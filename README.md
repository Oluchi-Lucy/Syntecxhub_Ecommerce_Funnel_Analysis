# E-commerce Conversion Funnel Analysis

# Overview
This project analyzes over 2.7 million user events from an e-commerce platform to understand the customer journey from viewing a product to completing a purchase.

# Objective
- Define and analyze funnel stages: View → Add to Cart → Purchase
- Calculate conversion rates between each stage
- Identify bottlenecks and drop-off points
- Visualize the funnel and suggest improvements

# Key Findings
- Only *0.84%* of product views convert into a completed purchase
- The biggest drop-off occurs between *View* and *Add to Cart* (2.60% conversion)
- Once an item is in the cart, *32.39%* of users go on to complete the purchase
- Over 2.59 million potential customers are lost at the "View to Cart" stage alone

# Recommendations
1. Improve product page experience (images, descriptions, pricing visibility)
2. Reduce friction to add items to cart
3. Retarget cart abandoners with reminders or discounts
4. Investigate high-traffic days to replicate successful patterns
